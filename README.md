# Mini Store

A modern and responsive e-commerce demo built with Next.js and React.

Mini Store is a portfolio project focused on building a clean shopping experience with product browsing, product details, cart management, theme switching, and a simple checkout flow.

## Live Demo

[View Live Demo](https://mini-store-azure.vercel.app/)

## GitHub

[View Source Code](https://github.com/adnandwere-dev/mini-store)

## Features

- Browse products from the Fake Store API
- Product details page
- Add products to cart
- Increase and decrease product quantity
- Remove products from cart
- Cart data persistence using localStorage
- Order summary with subtotal, tax, and total
- Simple checkout flow
- Order confirmation screen
- Light and Dark mode
- Responsive design for mobile, tablet, and desktop
- Loading, error, and empty states
- Accessible buttons, links, and images
- Responsive mobile navigation

## Tech Stack

- Next.js
- React
- Tailwind CSS
- JavaScript
- Lucide React
- Fake Store API
- localStorage
